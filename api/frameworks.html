Frameworks and Model Checking¶

This module connects to external frameworks, like stormpy for model checking. We include methods for building (I)MDPs from explicit environments, convenience functions for model checking and policy synthesis, as well as wrappers to apply shielding to environments.

Building stormpy models¶

verigym.frameworks.stormpy.stormpy_utils.build_stormpy_mdp(env: BaseExplicitEnv, overapproximate=True) → SparseMdp[source]¶

Builds a stormpy.storage.SparseMdp from a BaseExplicitEnv.

Parameters:

env (ExplicitEnv)

Returns:

mdp

Return type:

stormpy.storage.SparseMdp

Notes

  • Every state gets one choice per available action, i.e., per action with at least one successor in the transition function.

  • Choices are labelled with the env’s action names if it has action labels (e.g., when loaded from a prism file), and with the action indices otherwise. StormpyPolicy maps the choices of a scheduler back to the env’s actions in both cases (see its label_to_action parameter).

  • States without available actions are deadlocks. This includes states whose actions have no successors, which used to break the export. A deadlock gets a single unlabelled self-loop with probability 1 and zero reward, and the state label “deadlock”.

verigym.frameworks.stormpy.stormpy_utils.build_stormpy_imdp(env: BaseExplicitEnv, use_reward_uncertainty=False, overapproximate=True)[source]¶

Builds a stormpy IMDP from any BaseExplicitEnv. If used with an env without intervals instead of an interval env (IntervalEnvMixin, e.g., IntervalExplicitEnv), it will build an IMDP where lower bounds == upper bounds everywhere. Apart from the intervals, the IMDP is the same as the MDP of build_stormpy_mdp (see its notes on choices, choice labels and deadlocks).

Parameters:

  • env (BaseExplicitEnv) – The explicit env.

  • use_reward_uncertainty (bool = False) – Whether to build uncertainty over rewards. If True and the env is an interval env (IntervalEnvMixin), this will use the interval_reward_function. Else, it will use the reward_function and build interval rewards in stormpy where lower bounds == upper bounds. This is because standard (non-interval) reward functions are technically incompatible with the stormpy IMDP.

  • overapproximate (bool = True) – How to handle state labels for abstract state. If True, an abstract state gets assigned a label if any original state in it has the label. Else, an abstract state gets assigned a label only if all original states in it have the label.

Returns:

imdp

Return type:

stormpy.SparseIntervalMdp

Shielding¶

class verigym.supplements.shield_wrapper.AbstractPostShieldWrapper(env: VeriGymEnv, shield: ArrayLike, abstraction_mapper: AbstractionMapper, seed=None)[source]¶

Bases: Wrapper

Implements a simple post-shield over a Gymnasium-environment by overwriting the step function.

Initialises the AbstractPostShieldWrapper.

Parameters:

  • env (VeriGymEnv) – The VeriGym environment to apply the shield to.

  • shield (np.array) – An array of dimensionality (number abstract states, number actions). For each state-action pair: if shield[state, action] == True, the action is permitted. If False, the action is blocked.

  • abstraction_mapper (AbstractionMapper) – An abstraction mapper that maps to a discrete abstract state space on which the shield is defined.

  • seed (int, optional) – Seed of the random generator that chooses a safe action when the chosen action is blocked.

Notes

The input environment must have a discrete action space. The abstraction mapper must map to a discrete abstract state space.

reset(**kwargs)[source]¶

Overwrites Env.reset to store information of the current observation and info. If a seed is passed, the shield’s RNG for choosing a random safe action is reseeded as well.

step(action)[source]¶

Take a step in the shielded environment, with post-shield semantics. That is, after an action is proposed, the shield checks whether it is permitted. The shield is applied as follows:

If the abstract state corresponding to the current observation allows the chosen action,

returns the result of env.step with the chosen action.

Otherwise, the action is blocked. In that case:
If other actions are available in the state,

randomly chooses an available action, and returns the result of env.step with the random action.

Otherwise, if no permitted action is available, terminates the episode.
