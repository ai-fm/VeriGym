Model Components¶

The building blocks of explicit environments (see Environments). Transition and reward functions are stored as nested dicts over integer state and action indices, with interval variants for IMDPs, and the initial state distribution is stored sparsely. State labels assign names to states that satisfy a predicate, e.g., "goal" or "unsafe", so that model checking properties can refer to them. Formatters convert models from external frameworks into this representation, see Extending VeriGym in the import and export guide.

Transition functions¶

class verigym.TransitionFunction(n_states: int, n_actions: int, T_dict=None)[source]¶

Base class for transition functions in Verigym environments. It is based on dicts in dicts. All states and actions are flattened to integers indices. ✅ Indexing ❌ Slicing

Example:

T_array  # numpy array of shape (n_states, n_actions, n_states)
T = TransitionFunction.from_array(T_array)
s, a, s_next = 0, 0, 0
T[s, a, s_next] == T[s][a][
    s_next
]  # probability of transitioning from state s to s_next given action a
T[s][a]

point_estimate() → TransitionFunction[source]¶

Returns a point estimate within the intervals, used wherever a point estimate is required (e.g., to sample transitions). For each (s,a) pair, it takes the lower bounds and distributes the remaining probability mass over the successors proportionally to the widths of their intervals:

p(s') = lower(s') + (1 - sum(lower)) * (upper(s') - lower(s')) / sum(upper - lower).

If all intervals of (s,a) are points, p(s’) = lower(s’). If the intervals are valid (see sanity_check), every p(s’) lies in its interval and they sum to 1.

Keeps exactly the state-action pairs and successors of the intervals, and does not change the intervals.

Returns:

The point estimate.

Return type:

TransitionFunction

sanity_check() → bool[source]¶

Check if the transition function is valid, i.e., there exists a valid probability distribution in the intervals for each (s,a) pair. The sums of the lower and upper bounds are compared to 1 up to floating point precision (np.isclose), like the probabilities in TransitionFunction.sanity_check.

Reward functions¶

class verigym.RewardFunction(n_states: int, n_actions: int, R_dict=None)[source]¶

Class for reward functions in Verigym environments. It is based on dicts in dicts. All states and actions are flattened to integers indices. ✅ Indexing ❌ Slicing

Example:

R_array  # numpy array of shape (n_states, n_actions)
R = RewardFunction.from_array(R_array)
s, a = 0, 0
R[s, a] == R[s][a]  # reward for taking action a in state s
R[s]

Parameters:

  • original_labeler (StateLabeler) – The state label manager of the original environment

  • abstraction_mapper (AbstractionMapper) – Provides a mapping between original and abstract spaces. For abstractions from discrete state spaces, expects the abstraction_mapper’s backward map to return a set of states. For abstractions from continuous state spaces, expects original states characterized as a 2d list/array where list[0] = lower bound state valuations per dimension, and list[1] = upper bound state valuations per dimension.

Example

abstract_state_idx = 0
abstraction_mapper.abstract_to_original_state(abstract_state_idx)
# discrete:
[0, 1, 2]
# continuous:
[[-1, 1], [-2, 2]]

get_labels_of_abstract_state_exist(abstract_state)[source]¶

Returns state labels for an abstract state, based on the state labels of the contained original states. This function applies the exist operator, i.e., it overapproximates: If any of the original states contained in the abstract state has the label, the abstract state gets the label.

Parameters:

Returns:

labels – set of overapproximated state labels for the given abstract state.

Return type:

get_labels_of_abstract_state_forall(abstract_state)[source]¶

Returns state labels for an abstract state, based on the state labels of the contained original states. This function applies the forall operator, i.e., it underapproximates: Only if all original states in the abstract state have the label, the abstract state gets the label.

Convert a stormpy.storage.SparseMdp into a uniform format to support ExplicitEnvs/StormpyEnvs.

Also converts interval MDPs (stormpy.storage.SparseIntervalMdp): their transition probabilities and rewards are (lower, upper) tuples, in an IntervalTransitionFunction and an IntervalRewardFunction. Everything else (actions, labels, valuations, initial states) is the same for both.
